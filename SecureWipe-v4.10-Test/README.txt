SecureWipe v4.10 - USB Drive Utility
=====================================

Thank you for testing SecureWipe!

WHAT IS SECUREWIPE?
SecureWipe is a USB drive formatting and bootable media creation utility.
It's designed to be a streamlined, user-friendly tool for creating bootable
USB drives from ISO images.

SYSTEM REQUIREMENTS:
- Windows 10/11 (64-bit)
- Administrator privileges (required for USB operations)
- USB drive for testing

HOW TO USE:
1. Right-click on "securewipe.exe" and select "Run as administrator"
2. Select your USB drive from the dropdown
3. Choose an ISO file using the Browse button
4. Configure any options as needed
5. Click "Create" to start the process

IMPORTANT NOTES:
- BACKUP YOUR USB DRIVE: All data will be erased!
- Run as Administrator: Required for low-level USB operations
- This is a prototype version for testing purposes
- Please report any bugs or feedback
